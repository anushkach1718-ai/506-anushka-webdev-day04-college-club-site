# Campus Connect – College Club Website

## 📌 Project Overview

Campus Connect is a responsive four-page college club website developed using HTML5, CSS3, and JavaScript. The website provides students with information about the college club, upcoming events, membership registration, and contact details.

The main objective of this project is to create an attractive, user-friendly, and mobile-responsive website that helps students connect and participate in college activities.

## 🌐 Website Pages

1. **Home Page:** Introduces the college club and highlights its activities and features.
2. **About Page:** Provides information about the club, its purpose, and upcoming events in a table format.
3. **Registration Page:** Includes a student registration form with different input fields.
4. **Contact Page:** Displays contact information and provides a form for sending messages.

## 🛠️ Technologies Used

- HTML5 – Website structure and content.
- CSS3 – Styling, layout, colors, and responsive design.
- JavaScript – Interactive mobile navigation menu.

## ✨ Features

- Four interconnected website pages.
- Shared navigation menu across all pages.
- Attractive and modern user interface.
- Responsive design for desktop, tablet, and mobile devices.
- Accessible registration and contact forms.
- Event information table.
- HTML form validation.
- Mobile-friendly navigation.
- Consistent styling across all pages.

## 🚀 How to Run the Project

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Right-click and select **Open with Live Server**.
5. Explore all four pages using the navigation menu.
