# Campus Connect College Club

A responsive four-page college club website built with HTML5, CSS3 and a small amount of JavaScript.

## Pages
- `index.html` — home page and club introduction
- `about.html` — club story and accessible event schedule table
- `registration.html` — student registration form with different HTML input types
- `contact.html` — contact information and message form

## How to run
1. Download or clone this project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the **Live Server** extension in VS Code.
4. Use the navigation menu to visit the other pages.

## Project files
- `style.css` — shared responsive styling for all pages
- `script.js` — mobile navigation menu
- `favicon.svg` — website icon

## Note
The registration and contact forms are front-end demonstrations. They use browser validation but do not store or send submissions. Connect a backend or form service before using them to collect real responses.

Replace the sample club name, email, location and event details with your own college information.
